# go-project-management

프로젝트 관리를 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 범위·일정·원가·품질·위험·이해관계자 관리와 예측형·애자일·하이브리드 방식을, 한국의 제도(공공 SW사업, 국가계약법의 검사·계약금액 조정, 하도급, 건설사업관리) 위에서 배우고 PMBOK Guide·PRINCE2·ISO 21502 같은 국제 기준과 비교합니다.

처음 프로젝트를 맡은 분도, 오래 해 왔지만 체계와 제도 근거를 정리하고 싶은 관리자도 대상입니다. 마지막에는 내 실제 프로젝트에 쓸 계획서·WBS·위험대장 같은 산출물을 만듭니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료, 이미지를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-project-management
```

**Claude Code**

```bash
cd ~/Desktop/go-project-management
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 이때 이 폴더가 도구 권한 몇 가지를 미리 허용한다는 안내와 목록이 함께 뜨는데, 아래 「튜터가 쓰는 권한」에 적은 것들이므로 정상입니다. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-project-management` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 어떤 프로젝트를 해 봤는지(지금 맡은 일 포함) 짧게 묻고, 영역마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. 프로젝트가 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 내 프로젝트를 비튼 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다. 경력이나 자격증만으로는 넘어가지 않습니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML(공정표, 위험 지도, 계약 흐름도 등)을 만들어 가며 익힙니다. WBS·위험대장 같은 문서는 내가 직접 씁니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내가 쓴 문서. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 법령과 기준에 대해

- 튜터는 법령·고시의 조문 번호, 금액, 기한을 말하기 전에 국가법령정보센터 같은 공식 출처에서 다시 확인하고, 확인하지 못하면 그렇다고 말합니다. 그래도 법령은 바뀌므로 실제 업무에서는 원문을 직접 확인하세요.
- 튜터는 법률 자문을 하지 않습니다. 내 계약·분쟁의 결론은 계약 담당·법무·전문가와 확인하세요.
- 실제 계약서, 고객명, 금액, 개인정보는 붙여 넣지 말고 지운 요지만 말해 주세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 문서를 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 민감한 정보는 대화에 넣지 마세요.
